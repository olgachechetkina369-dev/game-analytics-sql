# Комплексный анализ игровой аналитики, динамики выручки и низкой активности пользователей (LMAU)

[👉 Ссылка на презентацию и видеоролик на Google Диске](https://google.com)

## Цель проекта:
Изучить динамику пользовательской базы, активность игроков, финансовые результаты и показатели вирусного роста для выявления причин падения метрик и поиска точек роста проекта Zombie Revolution.

## Методы анализа:
- Анализ выручки и оценка эффекта маркетинговых кампаний.
- Расчет и интерпретация показателей вирусности и удержания пользователей.
- Определение и сравнение когорт пользователей по различным критериям.
- Проверка статистических гипотез по целевым метрикам.

## Используемые инструменты:
- **SQL (PostgreSQL):** Написание аналитических запросов с использованием оконных функций (CASE WHEN, агрегации, JOIN-ы, CTE/подзапросы, EXCEL (постобработка/визуализация)), формирование выборок и очистка данных.
- **Excel / Google Таблицы:** Построение дашбордов, сводных таблиц, финальная постобработка данных и визуализация основных метрик (графики, дашборды).

## Что сделано (Ход работы):
1. Изучены исходные данные и проведён анализ количества пользователей и игровых сессий.
2. Рассчитана доля проблемных сессий по типам устройств и оценены возможные причины аномалий.
3. Определен коэффициент вирусности игры и средний размер будущих когорт пользователей.
4. Проанализирована динамика выручки и влияние маркетинговой кампании на финансовые показатели.
5. Оценены изменения ключевых метрик DAU / WAU / MAU и их соотношение.
6. Рассчитана доля лояльных пользователей, протестированы разные критерии определения лояльности.
7. Результаты подготовлены и оформлены в виде структурированной презентации со всеми ключевыми выводами.
8. ## Ключевые результаты для бизнеса:

- **Выявлены причины падения LMAU:** Зафиксированы технические аномалии и проблемные сессии на определённых типах устройств, из-за которых снижалась активность пользователей. Сформированы рекомендации для команды разработки по устранению багов.
- **Оценен эффект маркетинговой кампании:** Рассчитано влияние рекламы на динамику выручки и привлечение новых игроков. Выделены наиболее эффективные когорты пользователей для оптимизации будущих рекламных бюджетов.
- **Определен портрет лояльной аудитории:** Протестированы различные критерии лояльности пользователей, на основе которых предложены механики для удержания игроков и повышения метрик DAU / WAU / MAU.
- **Рассчитан потенциал вирусного роста:** На основе коэффициента вирусности сделан прогноз органического прироста будущих когорт, что позволит точнее прогнозировать нагрузку на сервера и финансовые поступления.
